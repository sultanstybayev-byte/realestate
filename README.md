# Сайт: продажа дома в Кызыл-Кайрате

Одностраничный сайт для рекламы в соцсетях. Всё в одном файле `index.html`, фото в папке `img`.

---

## 1. Как разместить сайт на GitHub (один раз, ~10 минут)

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. Справа вверху нажмите **+** → **New repository**.
   - Repository name: например `dom-kyzyl-kairat`
   - Выберите **Public**
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте архив на компьютере и перетащите в окно браузера **файл `index.html`, файл `README.md` и папку `img` целиком**.
   Внизу нажмите **Commit changes**.
5. Откройте **Settings** → слева **Pages**.
   В блоке *Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты обновите страницу Pages: сверху появится адрес сайта вида
   `https://ВАШ-ЛОГИН.github.io/dom-kyzyl-kairat/`
   Эту ссылку и вставляйте в рекламу.

## 2. Как редактировать визуально (без кода)

1. Откройте свой сайт и допишите в конце адреса **`#edit`**, например:
   `https://ВАШ-ЛОГИН.github.io/dom-kyzyl-kairat/#edit`
   (или откройте файл `index.html` из архива на компьютере в браузере и допишите `#edit`).
2. Появится панель «Редактирование сайта»:
   - **кликайте по любому тексту** на странице и исправляйте его прямо на месте;
   - в панели впишите **телефон, имя, площадь, цену** и текст первого сообщения в WhatsApp;
   - в галерее подписи фото меняются кликом, **×** убирает фото.
3. Нажмите **«Сохранить файл index.html»** — файл попадёт в «Загрузки».
4. На GitHub в репозитории: **Add file → Upload files** → перетащите этот `index.html` → **Commit changes**.
5. Через 1–2 минуты сайт обновится. Посетители панель редактирования не видят — она открывается только с `#edit`.

Правки в режиме `#edit` не сохраняются сами — обязательно нажмите «Сохранить файл» перед тем, как закрыть страницу.

## 2б. Как редактировать в коде (если нужно)

1. В репозитории откройте файл `index.html`.
2. Нажмите значок **карандаша** (Edit) справа вверху.
3. Найдите нужное место через **Ctrl+F** (на Mac **Cmd+F**) — подсказки ниже.
4. Измените текст и нажмите зелёную кнопку **Commit changes** → ещё раз **Commit changes**.
5. Через 1–2 минуты изменения появятся на сайте (обновите страницу).

Если что-то сломалось: откройте файл → **History** → выберите прошлую версию — всё можно вернуть.

## 3. Что заполнить в первую очередь

### Телефон и WhatsApp
Ищите: `Контакты: замените здесь`

```js
const PHONE = "77000000000";            // номер без + и пробелов, например 77011234567
const PHONE_SHOWN = "+7 7__ ___ __ __"; // как номер видят на сайте, например +7 701 123 45 67
const MSG = "Здравствуйте! ...";         // первое сообщение, которое придёт вам в WhatsApp
```

### Имя
Ищите: `Собственник,` и замените
`<span class="ph">имя</span>` → просто `Арман` (своё имя).

### Площадь дома
Ищите: `площадь дома` — строкой выше
`<span class="ph">—</span>` → просто число, например `420`.

> **Пунктирное подчёркивание** — это класс `class="ph"` (заглушка).
> Когда вписываете настоящие данные, удаляйте обёртку `<span class="ph">…</span>`, оставляя только текст.

### Цена
Ищите: `350 000 000` (на первом экране) и `350 млн` (кнопка внизу на телефоне). Также цена есть в тексте заявки: ищите `350 млн ₸`.

## 4. Фото

- Чтобы **заменить фото** — загрузите новое в папку `img` с тем же именем (Add file → Upload files). Размер лучше до 1600 px по длинной стороне.
- У каждого фото две версии: `имя.jpg` (большая, открывается по клику) и `имя-s.jpg` (маленькая, для превью).
- **Подписи и порядок фото в галерее** — ищите `Галерея:`. Каждая строка выглядит так:
  `["kitchen","Кухня-столовая","w"]` — файл, подпись, форма плитки (`w` широкая, `t` высокая, `""` обычная).
  Удалить фото из галереи — удалите его `[...]` вместе с запятой.

---

## 5. Красивое превью ссылки в соцсетях

Когда сайт заработает, найдите `og:image` и замените `img/hero.jpg` на полный адрес:
`https://ВАШ-ЛОГИН.github.io/dom-kyzyl-kairat/img/hero.jpg`
Тогда в WhatsApp, Telegram и Instagram ссылка будет показываться с фото дома.
